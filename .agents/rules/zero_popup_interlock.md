# 常规任务权限规则

1. 本文件是操作指导，不是系统权限配置，不保证任意任务零弹窗。
2. 优先使用原生读写工具；允许必要的只读终端检查，不根据上下文猜测 Git 状态。
3. 整文件覆盖：本会话新建、完成成功且内容未被用户修改的文件可以由 Hook 自动批准。临时目录名不代表所有权。
4. 字符串 `replace()` 与文件 `Path.replace()` 不等价。只有接收者类型明确的字符串清洗可以自动批准，未知 Python 调用仍需审查。
5. 明确的 `2>/dev/null` 不覆盖用户文件，其他文件重定向、动态结构和未知入口继续询问。
6. 根目录来自实际 `workspacePaths`；Artifact 匹配当前宿主和 `conversationId`，不把所有 brain 目录当作本任务目录。
7. 每个实际路径先检查再操作；`TMPDIR` 和注释不能替代沙箱，`tempfile` API 显式指定 `dir=`。
8. 删除、移动、系统权限、配置修改、越界、反射、未知依赖和检查失败继续 `force_ask`。不要隐藏在脚本内或自动点击授权。
9. 固定文本入口仅接受 JSON 参数，新输出排他创建；已有输出须确认并备份。复杂解析与第三方库仍需按实际任务审查。
10. 自检报告配置哈希和行为案例，真实应用、两次重启和第二台电脑另行验收，没有现场证据就标记待验证。
